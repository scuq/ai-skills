# Sources

The rules in this skill are distilled principles.
They are not verbatim requirements.
Do not cite a clause or a paragraph number from memory.
Direct the user to the current revision of the source document instead.

| Source | Domain | Contributes |
|---|---|---|
| NASA-STD-3001 Vol. 2 (Human Factors, Habitability, and Environmental Health) | Human spaceflight | Display consistency, critical information availability, the labeling plan, the icon library, controlled deviations |
| NASA Human Integration Design Handbook (HIDH) | Human spaceflight | The rationale behind NASA-STD-3001 |
| FAA HF-STD-001 (Human Factors Design Standard) | Aviation, air traffic control | Color consistency across applications, redundant coding |
| MIL-STD-1472 (Human Engineering) | Defense | General human-engineering design criteria |
| NUREG-0700 (Human-System Interface Design Review Guidelines) | Nuclear control rooms | The human-system interface review method |
| ANSI/ISA-101.01 (HMI for Process Automation) | Industrial control | The high-performance HMI, the muted normal state, display hierarchy |
| ANSI/ISA-18.2, IEC 62682 | Industrial control | The alarm lifecycle, rationalization, shelving, ack compared with clear |
| EEMUA 191 | Industrial control | Alarm system performance metrics |
| IEC 60073 | Electrical equipment | Color coding of indicators and actuators |
| WCAG 2.2 | Web | Contrast and non-color-only information (SC 1.4.1, 1.4.3, 1.4.11) |
