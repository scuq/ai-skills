## Statement

Automated checks have limits. `ste-lint.py` tests sentence shape. It does not test meaning or dictionary compliance. The reviewer does.
Confidentiality is a policy decision of the organization, not of this standard. Run the agent only where your policy lets the source and its documentation go.
